# Security

If you discover a security vulnerability in this project, please report it privately so
we can address it responsibly.

Preferred reporting process
1. Open a private issue and add `security` to the title, or
2. Contact the maintainers directly at `abhirajgautam28@gmail.com`.

Please include:
- A clear description of the vulnerability
- Steps to reproduce
- Any proof-of-concept code

We will respond quickly and coordinate a fix and disclosure timeline.
