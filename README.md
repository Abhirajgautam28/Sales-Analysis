# Warehouse Sales Analysis — Interactive Sales Analytics

## Project Summary

Warehouse Sales Analysis is an end-to-end analytics project that transforms raw sales, customer, product, and regional data into actionable insights. The repository includes data processing pipelines, exploratory data analysis (EDA), interactive visualizations, and a live web app for stakeholders to explore trends, product performance, and regional sales distribution.

**Live demo:** [https://warehouse-sales-analysis.streamlit.app/](https://warehouse-sales-analysis.streamlit.app/)

## Key Features

- Cleaned and merged datasets from sales orders, customers, products, regions, and budgets.
- Exploratory Data Analysis with interactive charts for monthly trends, top products, channel breakdowns, and customer segmentation.
- Geographic visualization (U.S. choropleth) for state-level sales insights.
- Interactive Streamlit app for on-demand filtering, KPI tiles, and data downloads.

## Tech Stack

- Python: `pandas`, `numpy`, `matplotlib`, `seaborn`, `plotly`.
- Web app: `streamlit` for interactive dashboards.
- Data pipeline / storage: `MySQL` (ETL examples included).
- Reporting: `Power BI` (example dashboards and exportable assets).

## Repository Contents

- `EDA_Regional_Sales_Analysis.ipynb` — Notebook with detailed EDA and visualizations.
- `app.py` — Streamlit application for live interactive analytics.
- `Sales_data(EDA Exported).csv` — Exported dataset used by the notebook and app.
- `Data_split/` — CSVs and supporting tables (Customers, Products, Regions, Budgets).
- `SQL_codes/` — SQL scripts for loading and creating relational tables.
- `requirements.txt` — Python dependencies for local development and deployment.

## Quickstart (Local)

1. Clone the repo:

```powershell
git clone https://github.com/Abhirajgautam28/Sales-Analysis.git
cd Sales-Analysis
```

1. Create a virtual environment and install dependencies:

```powershell
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

1. Run the Streamlit app locally:

```powershell
streamlit run app.py
```

## Deployment

The app is deployed on Streamlit Community Cloud and available at: [https://warehouse-sales-analysis.streamlit.app/](https://warehouse-sales-analysis.streamlit.app/)
