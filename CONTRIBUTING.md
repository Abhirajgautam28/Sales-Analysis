# Contributing

Thanks for your interest in contributing to Warehouse Sales Analysis — contributions are welcome!

How to contribute
- Fork the repository and create a feature branch: `git checkout -b feat/your-feature`
- Make small, focused commits and keep your branch up to date with `main`.
- Run any relevant checks locally (see `requirements.txt`).
- Open a Pull Request with a clear title and description describing the change and why it helps.

Code style and tests
- Follow Python best practices (PEP8). Use sensible variable names and keep functions small.
- Add tests where appropriate. The CI checks will validate dependencies and run basic import checks.

PR process
- A maintainer will review your PR and request changes if needed. Keep PRs small and focused.
- Once approved and CI checks pass, a maintainer will merge your changes.

Communication
- For feature discussions open an issue first to get alignment.
- For sensitive or security issues, see `SECURITY.md` for private reporting instructions.
